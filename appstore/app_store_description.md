## Description

Nodus is a minimal Zettelkasten note-taking app for iPhone and iPad. Your notes are plain Markdown files stored in iCloud Drive — no proprietary format, no lock-in, no subscription.

**Why Nodus?**
Most note apps are too complex. Nodus focuses on what matters: writing, linking, and thinking.

**Features**
- Plain Markdown files in iCloud Drive — open with any Markdown editor on Mac or iOS
- Wiki-style links with [[timestamp]] syntax that survive title renames
- Fast full-text AND search across filenames and body text
- Clean edit / preview toggle with full GFM Markdown rendering
- Sort by updated date, created date, title, backlink count, or random
- Created and updated timestamps read from the file system — no front matter needed

**Your files, your way**
Select any folder in iCloud Drive as your Zettelkasten. Use Nodus alongside your existing notes and desktop editors — everything stays in sync automatically.
